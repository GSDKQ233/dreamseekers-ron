# 寻梦者功能说明

寻梦者将原版 PasterDream 的生物与梦境主题引入 Reign of Nether 的即时战略玩法。玩家以世界树主城建立基地，由寻梦萤火虫采集资源、建造设施，再通过训练、研究和技能配合组织军队。

本文介绍 `autocast.1-alpha` 附属的现有玩法。核心仍使用 API65 `repair3.1`；其修复范围见 [repair3.1 验收说明](REPAIR3.1.zh-CN.md)。安装所需文件与兼容范围见[安装与更新指南](INSTALL.zh-CN.txt)。具体费用、人口、时间、范围和解锁条件以游戏内当前提示及服务端状态为准。

## 经济与成长

寻梦者沿用核心的资源与人口系统，并使用专属影能参与研究、技能和部分单位训练。梦生花园自动提供食物，潜影矿井提供矿石，凝影炉场提供影能；逐梦货栈用于交回工人携带的资源。自动产出需要建筑与所属账户处于有效状态，不按停服时长补产。

同一座世界树主城可以先升影世界树，再升风之旅途，也可以反过来。两次各付各的原价，各需 2400 工作刻，不能同时开工。第一条分支在第二次升级期间仍然生效；取消第二次升级只退回这次付款。两条都完成后成为影风共生世界树：影路线的定期收入、升华研究前置，与风之旅途的训练折扣和科技成长可以同时生效。占领不是购买，不会把原付款人的永久风科技转给占领者。共鸣研究院还提供兵种专精、契约扩容、共鸣调律及进阶战术研究。

主城的两项研究各有三级，同一玩家的多座主城共享进度。**影能转化精研**将敌军阵亡时按其食物、木材与矿石造价折算的影能比例从 5% 逐级提高至 10%、15%、20%。**世界树升华共鸣**需在已完成影分支的主城研究，为己方 RTS 单位提供 +15%、+30%、+45% 的生命上限和普通攻击加成。每级单独付费，二、三级的基础费用和研究时间分别为一级的两倍和三倍。

训练和研究使用付费队列。单位训练受人口、建筑前置、所属阵营及生成空间约束；研究也须满足自身的建筑与解锁条件。前置条件暂时失效或出兵位置受阻时，相关生产可能暂停，请按界面提示恢复条件或取消。

## 建筑用途

| 建筑 | 主要用途 |
| --- | --- |
| 世界树主城 | 训练工人、交回资源、提供人口，并承载主城升级与经济研究 |
| 梦生花园 | 自动产粮、提供人口，以及为符合条件的脱战单位提供庭园休养 |
| 破风训练庭 | 训练基础战斗与支援单位，部分兵种需要契约生态庭 |
| 逐梦货栈 | 作为工人资源交回点，缩短运输路线 |
| 潜影矿井 | 在有效运行状态下自动产出矿石 |
| 凝影炉场 | 为符合阵营条件的所属账户自动产出影能 |
| 梦术礼堂 | 分页训练进阶兵种，并提供有前置条件的术式整备能力 |
| 共鸣研究院 | 研发阵营成长、兵种专精及战术科技 |
| 契约生态庭 | 支持中立契约、单位派驻照护与生态图鉴 |
| 共鸣晶台 | 连接世界树共鸣网络，提供生产增益、共鸣脉冲与有研究前置的庇护 |
| 影灯守望塔 | 容纳适合驻军的单位，并在满足条件时使用照影标记 |

花园中的麦穗是装饰。守望塔由驻军开火；历史实心塔重建为新版结构后即可驻军。

## 单位与战术

- **建设与侦察**：寻梦萤火虫负责采集、建造与中立契约；粉红鸡侦察兵可对合法可见目标使用侦察标记。
- **基础战斗与支援**：厚翅甲虫卫士、玄武蜗牛守卫、粉红史莱姆护卫、水母和金色狐狸，配合展翼顶进、守壳阵、凝胶护持、缓回浮流与辉梦祝福等能力。
- **礼堂兵种**：骨翼、破风骑士、小石灵投手、厚翅甲虫之母及影系单位，覆盖突击、投射、召唤、控制与建筑作战等用途。各兵种的能力见其技能说明。
- **影系编队**：怨魂、尖啸怨魂、恐怖尖喙、契约幽魂、暗影之手、余烬骨翼、阴影傀儡与悲泣尖啸怨魂，可通过蚀甲、压制、牵制及范围打击配合行动。疯狂恐怖尖喙通过既有升级流程获得，不是独立的普通训练项目。
- **亚伦柯斯之触**：左手和右手分别训练，需满足研究院、已升级世界树、费用与人口要求。双手共契保留各自生命值，在符合条件时分摊伤害；阵亡后的补手是有条件的付费新单位，不是无条件复活或共用一条血条。

23 项单位主动技能中，12 项默认开启自动施放，其余 11 项只手动施放。选中单位后，右键技能按钮可单独开关该单位的这一项自动施放；左键仍可手动用。正在选目标时，右键或 Esc 是取消选点。例如，金狐会祝福已经能攻击当前目标的友军；玄武蜗牛则须先接到“原地驻守”，才会对瞄准自己且在射程内的远程敌军自动结阵。破风突击、归巢急行等会改变队形或打断工作的技能仍由玩家决定时机。

旧存档中的寻梦小石精保留原注册身份；当前工人为寻梦萤火虫。技能召唤物为临时单位，随施法者存在。

## 共鸣与生态

**共鸣网络**由世界树连接附近晶台，并经有效节点向外延伸。晶台的网络状态、相关研究和目标资格共同决定共鸣能力是否可用；建筑拆毁、转属或断联会使依赖该来源的效果失效。辉梦共振仅增强指定的支援技能。施法者距己方已激活晶台基底最近点不超过 12 格方可获得增幅，计入高度差。

**中立契约**由寻梦萤火虫接近并引导，消耗资源与人口，将符合条件的原生野生甲虫或玄武蜗牛转化为己方 RTS 单位。该功能受契约生态庭覆盖、容量、目标状态与视野约束，不会接管玩家宠物、命名生物或任意中立生物。

**生态图鉴**用于查看当前自有、同维度、已加载的单位，并管理生态庭派驻。照护需要对应研究及符合条件的目标；图鉴列出已加载区域内的单位。

## 塔防生存

寻梦者可以在塔防生存中自行建造现有信标。先完成至少一条世界树分支（影、风、影风共生均可）和一座共鸣研究院，再用寻梦萤火虫按正常规则付费建造、升级并守护。地图已配置的信标、禁建规则以及全图唯一限制照旧。这不是敌方波次的阵容变更，也不会改变其他模式的信标资格。

## 使用要点

- 将生产建筑出口留空，避免单位完成训练时被实体、建筑或地形阻挡。
- 注意科技前置和技能目标类型；技能目标须可见、有效、在射程内且符合阵营关系。
- 侦察标记与照影标记显示视野内的可见敌人；守望塔标记作用于塔的视线范围内。
- 部分技能具有持续效果、召唤上限或有效来源条件。切换命令、单位离开范围或来源失效时，按该技能规则结束或中止效果。
- 保存与升级前正常退出。重启后请重新施放进行中的技能；产出与研究在区域加载且服务器运行时推进。
