# 寻梦者建筑造型更新

本分支以已整合美术 PR 的主线为基准，接入 11 种寻梦者建筑的 13 个新造型。保留既有单位头像、技能图标、施法动画和建筑数值；不合并另一套建筑 PR。没有引入第三方模型、贴图或依赖 JAR。

| 建筑组 | 本次造型 |
| --- | --- |
| 世界树 | 抱月树庭、蚀环影树、风羽三帆树 |
| 防务 | 燧羽哨塔（影灯守望塔） |
| 经济 | 蝶翼露棚（花园）、折帆转运栈、绞轮矿井、月蚀坩埚 |
| 训练与研究 | 破风训练庭、梦术礼堂、共鸣研究院 |
| 特色建筑 | 契约生态庭、共鸣晶台 |

现有建筑 ID 不变。旧结构保留原字节，新结构以独立模板名和修订号储存。已有建筑按原版几何恢复；已排定的世界树变形目标也保留其原版本。新建筑采用新模板，之后发起的升级使用新支系。此更新不批量转换旧建筑。

花园仍使用原来的 16 个种植坐标，并沿用将模板小麦转换成装饰小麦的流程。守望塔保留驻军承托、出口和观察位置。破风训练庭有两格地基草块完全被实体方块盖住，仅新模板在运行时将其计为泥土，以免自然退化后反复触发修理；原始模板和可见表面不变。新世界树受损升级时，挂灯只在相应方块支撑保留后纳入重建。建筑建造和损坏仍按实际模板方块计算，方块数变化不等于另行修改建筑数值。新旧模板的计数和校验和分别记在 [结构清单](../../addons/dreamseekers/structure_manifest.json)。

客户端和服务端应同时升级为相同新附属版本，不与旧附属混用。环境仍为 Minecraft Java 1.20.1 / Forge 47.4.0 / Java 17。先备份现有存档，用副本试跑。这里是待审源码，不是发布版本或旧版本的存档回滚承诺。
